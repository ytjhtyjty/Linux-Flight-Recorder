# Changelog

## 0.1.0 — development, unreleased

- Read-only Linux snapshots, three package inventory adapters, bounded journal and systemd collection.
- Private transactional SQLite storage, integrity checks, pins and retention.
- Conservative offline comparison, evidence-based hypotheses, Markdown/JSON and previewable exports.
- Corrected journalctl access-denial classification with a regression and real Debian verification.
- Reproducible rootless QEMU TCG validation with controlled guest changes and failure injection.
- Public-source cleanup: English documentation, explanatory code comments removed without changing logic,
  and binaries, raw logs, VM images, keys and generated dependency inventories excluded.

This is not a stable release. Known bugs/limitations and untested areas are
listed in [validation](docs/validation.md) and [release gates](docs/RELEASE.md).
